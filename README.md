# Aanya's portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser, or use VS Code's Live Server extension.

## Personalise before publishing
1. Replace the placeholder images in `img/projects/` with your project screenshots, PCB renders or CAD images.
2. Copy your existing astrophotography images and `star.png` into the `img/` folder, keeping the filenames used in `index.html`.
3. Update project links to the exact repositories and demos.
4. Replace `YOUR_EMAIL@example.com` with the email address you want to publish.
5. Adjust descriptions and Solo/Team tags so they accurately reflect your contribution.

The GitHub links currently use the profile `wisegirl139-sudo`; the SelPad card links to the repository shared in the project context. Other project links are profile placeholders until their exact repository URLs are added.

## Publish with GitHub Pages
Push the folder contents to a repository, then open the repository's **Settings → Pages**. Choose deployment from the `main` branch and `/ (root)` folder, then save. GitHub will provide the published site URL once deployment completes.
